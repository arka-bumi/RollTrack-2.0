## 3. Flow (diperbarui)
Login PIN (1.1) → Beranda KPI+feed (1.2) → Pindah: 2.1 → 2.2/2.3 modal → 2.4 rekap gudang-tujuan → eksekusi → kembali ke 2.1 fresh (reset + toast) / Cutting: **pilih merek → produksi/non-produksi → tanggal + NN → pilih produk (auto nama + varian) → preview + kunci kode → Tambah Roll Kain loop** (3.2/3.3 modal per roll: VALID + Roll ID + jenis•motif•SKU + Sisa Meter Terkini saja → Panjang(m)/Estimasi(Kg) + radio Sisa/Habis + preview live) → 3.4 waste → **Simpan Transaksi** (N baris 1 kode) → kembali ke 3.1 fresh (reset batch + toast sukses, siap pilih merek lagi); 3.5 nonprod (nama bebas, kode/SKU dikosongkan) / Kain: 4.1 ↔ 4.2, 4.3 ↔ 4.4, 4.5 download / Profil: 5.1 vs 5.2 (SO locked) / Sync: 5.3 ↔ 5.4/5.5, 5.6.
Tanpa harga, tanpa sinyal PO, tanpa ruangan, tanpa blokir stok negatif. Status `1 Roll / Sisa / Habis`, kunci Roll ID.

## 4. Aturan Lintas Layar
1. **Pemilih merek:** toggle di 3.1, 3.5 (Cutting) dan 4.1–4.5 (Kain); prefix kode M/A mengikuti; seluruh rujukan merek lain mengikuti pilihan ini. **Pindah Gudang (2.1–2.4) tidak punya toggle** — fokus pada roll, lintas merek.
2. **Kode Produksi:** format terkunci `{M|A}{DDMMYY}-{SKU}-{NN}`; NN manual; preview live di kotak KODE PRODUKSI lalu **kunci via ikon gembok** (selama terkunci, dropdown produk/tanggal/NN tak bisa berubah — mencegah klik tak sengaja mengganti kode); buka gembok mengembalikan produk/tanggal/NN ke bisa-diubah tanpa me-reset batch (roll yang sudah ditambahkan tetap); satu kode menampung **N roll** (Tambah Roll Kain loop, Simpan Transaksi = N baris); duplikat ditolak dengan pesan jelas. Setelah Simpan berhasil (3.1/3.5) kembali ke 3.1 fresh (reset: kunci dibuka, roll dikosongkan, produk/NN direset, tanggal default hari ini) + toast sukses; gagal tetap di layar.
3. **Master produk hidden:** tidak ada layar daftar produk; dropdown = Aktif + merek aktif + dedup per SKU Produk; cari by SKU/nama (substring, case-insensitive), label `{SKU Produk} - {Produk} - {Varian}`, urut Nama A→Z lalu Varian S→M→L→XL lalu SKU; auto Nama + **Varian size** (S/M/L/XL; SKU beda per size); **relasi kain tidak dipakai untuk display roll**.
4. **Tanpa ruangan:** kata ruangan/rak dihapus dari semua teks Pindah (2.1–2.4 + rekap). Pindah bersifat **bulk**: satu asal gudang terkunci → satu tujuan, banyak roll, satu klik eksekusi; daftar gudang (2.4) berasal dari **Master Gudang** dan sama untuk kedua merek. Setelah Eksekusi berhasil kembali ke 2.1 fresh (reset daftar, kunci asal dibuka, tanggal default hari ini, tujuan dikosongkan) + toast sukses; gagal tetap di 2.4.
5. **Tombol Profil ganda:** Keluar Aplikasi (tutup app) vs Log Out (kembali ke 1.1), di 5.1 dan 5.2.
6. **Sumber data dashboard:** 4.1/4.3 baca operasional terkini sesuai merek yang dipilih toggle; tab Summary Sheets = pembanding audit; card expand 4.1 dari group-by SKU (`{SKU, total_roll, total_sisa, rolls:[{roll_id, sisa, status, gudang}]}`). Tanpa penanda stok menipis (abaikan warna merah di mockup).
7. **Tombol sync:** Sinkron Database (master + summary, ringan) vs Sinkron Penuh (history, berat); SO tetap locked di 5.2.
8. **Koneksi Spreadsheet (Super Admin):** halaman **terpisah** (bukan bagian 5.6) untuk mendaftarkan **2 Spreadsheet ID** (Malilkids & Anakkecilku) + status Uji Koneksi. Isi halaman (spek teks, tanpa contoh visual): 2 kolom input Spreadsheet ID (satu per merek) + tombol Uji Koneksi per merek + status baca/tulis per merek. Kredensial service account **tidak pernah** diinput lewat aplikasi.
9. **Header layar:** pakai bahasa mockup apa adanya (Moving, Fabrics, Cutting, Profil).
10. **Divergensi mockup Stitch yang disengaja (3.2/3.3):** kolom `Sisa Berat Fisik` yang masih tampil di canvas/mockup **dihapus dari spek** (keputusan: jarang dipakai, kolomnya tidak ada di spreadsheet, meringankan proses). Mockup **tidak diperbarui**; dokumen ini yang berlaku — kartu scan cutting hanya menampilkan Sisa Meter Terkini.
11. **Stock Opname terkunci:** tombol SO di 5.2 tampil nonaktif dengan ikon gembok; untuk pengembangan selanjutnya (spek penuh PRD §3.7 tetap berlaku).
